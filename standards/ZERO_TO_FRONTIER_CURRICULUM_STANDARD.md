# SKA Zero-to-Frontier Curriculum Standard

Status: canonical expansion specification
Scope: every public educational subject
Purpose: ensure a learner can enter with no assumed subject knowledge and progress through advanced, computational, AI-augmented, professional, and research-aware study.

## Core requirement
A subject is not complete merely because a subject file exists. Each subject must define a prerequisite path, teach concepts in dependency order, provide worked reasoning and practice, assess mastery, remediate failure, and connect advanced study to modern computational and AI-assisted practice.

## Required progression
1. Orientation and prerequisite literacy
2. Absolute beginner foundations
3. Elementary foundations
4. Secondary-school equivalent
5. Advanced secondary / pre-university
6. Undergraduate foundations
7. Advanced undergraduate
8. Graduate foundations
9. Advanced graduate / professional specialization
10. Computational and tool-assisted practice
11. AI-augmented practice
12. Frontier/research literacy

These stages are competency bands, not claims of institutional accreditation.

## Required lesson schema
Every instructional unit should contain:
- canonical discipline and subject
- prerequisites and dependency IDs
- explicit learning objectives
- vocabulary and notation
- first principles
- conceptual explanation
- derivations or causal mechanisms where applicable
- multiple worked examples
- guided practice
- independent practice
- common misconceptions and failure modes
- edge cases and counterexamples
- real-world and cross-disciplinary applications
- computational treatment where relevant
- AI-augmented treatment where relevant
- summary and retrieval cues
- formative quiz
- problem set
- verified solutions/explanations
- mastery threshold
- remediation route
- next-unit dependencies
- Education-16 placement
- Symbol256 mapping metadata

## Assessment standard
Assessments must progress beyond recall:
recall -> comprehension -> application -> analysis -> multi-step reasoning -> synthesis -> transfer -> proof/derivation/design where appropriate.

Generated questions that are grammatically valid but semantically weak do not count toward mastery coverage. Distractors must be plausible. Correct answers require explanations. Advanced subjects require cumulative examinations, projects, implementations, proofs, laboratories, case analysis, or research exercises as appropriate.

## Mathematics pathway
Numeracy -> arithmetic -> fractions/decimals/percent -> ratios/proportions -> pre-algebra -> Algebra I -> geometry -> Algebra II -> trigonometry -> precalculus -> Calculus I -> Calculus II -> multivariable calculus -> linear algebra -> discrete mathematics and logic -> differential equations -> probability -> mathematical statistics -> real analysis -> complex analysis -> abstract algebra -> number theory -> numerical analysis -> optimization -> topology -> measure theory -> functional analysis -> differential geometry -> algebraic geometry -> category theory and advanced specializations.

Modern mathematics must also cover computational mathematics, symbolic computation, numerical computing, computer algebra, automated theorem proving, formal verification, constraint programming, SAT/2-SAT/3-SAT/Max-SAT/weighted Max-SAT, SMT, mathematical modeling, simulation, proof assistants, AI-assisted conjecture generation, AI-assisted proof workflows, equation discovery, solver orchestration, and verification of machine-generated mathematical claims.

SKA-defined mathematics and experimental research must be clearly distinguished from established mathematics and externally validated results.

## English pathway
Pre-literacy/orientation -> letters, sounds and word recognition -> vocabulary -> sentence construction -> grammar -> punctuation -> spelling -> reading comprehension -> paragraph construction -> composition -> informational writing -> narrative writing -> argumentation -> rhetoric -> research literacy -> source evaluation -> citation -> literary analysis -> language history -> linguistics foundations -> advanced grammar and syntax -> professional/technical writing -> academic writing -> editing -> discourse analysis -> stylistics -> corpus methods -> computational linguistics foundations -> digital communication -> AI-assisted drafting, revision, analysis and verification.

English mastery must include reading, writing, listening, speaking, reasoning about language, research, argument evaluation, audience adaptation, revision, and modern human-AI communication. AI assistance must not replace independent literacy; learners must be able to evaluate and correct machine output.

## Domain adaptation
The same zero-to-frontier pattern applies according to discipline. Science requires observation, quantitative reasoning, laboratory methodology, modeling, uncertainty and scientific communication. Computing requires theory plus implementation, debugging, systems thinking, security and projects. Business requires quantitative literacy, cases, decisions, simulations and current digital/AI operations. Humanities require primary/secondary source analysis, interpretation, argument and historiography. Professional disciplines require applicable practice, ethics, standards and scenario assessment.

## Knowledge/identity separation
Public educational material teaches transferable knowledge and methods. Tenant identity, company identity, private data, offers, policies and agent representation are not embedded as universal educational facts. Runtime identity routing determines whom a custom agent represents.

## Completion rule
A subject can be marked COMPLETE only when its declared lesson count is actually populated, prerequisite coverage is closed, assessments pass semantic-quality checks, solutions are verified, taxonomy is canonical, and the beginner-to-frontier dependency path contains no unresolved instructional gaps.
