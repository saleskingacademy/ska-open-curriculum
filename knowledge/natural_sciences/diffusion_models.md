# Diffusion Models

> The course teaches core concepts and principles of diffusion models, assuming some basic knowledge of mathematical and computational terminology.

## Foundations

Diffusion models are rooted in the concept of a **Markov chain**, a mathematical system that undergoes transitions from one state to another, where the probability of transitioning from one state to another is dependent solely on the current state and time elapsed. The core definition of a diffusion model involves a process that progressively refines an input, often an image or data point, by iteratively adding or removing **noise**, which is a random fluctuation or disturbance in the data. **Noise schedules** are a crucial component, defining the amount and type of noise added at each step of the diffusion process.

A **diffusion step** is a single iteration in this process, where the input is transformed based on a **transition probability**, which is the probability of moving from one state to another. The **stationary distribution** is the long-term distribution of states that the Markov chain converges to, given infinite time. In diffusion models, this often represents the target distribution that the model aims to learn or generate samples from.

Understanding **reversibility** is also key, as it refers to the ability of a diffusion process to be run in reverse, transforming a noise distribution back into the original data distribution. This principle is fundamental to training diffusion models, as it allows for the learning of complex data distributions by reversing a simple noise schedule. **Loss functions**, such as the **reconstruction loss**, are used to train these models, measuring the difference between the original input and its reconstruction after passing through the diffusion and reverse processes.

In computer science, diffusion models refer to a class of deep learning models that utilize a process called diffusion-based image synthesis. A **diffusion process** is a Markov chain that progressively adds noise to an input data distribution until the data becomes indistinguishable from random noise. The core concept of diffusion models is to learn the reverse process, called **denoising**, which transforms the noise back into the original data distribution. This is achieved through a **neural network**, a computational system composed of layers of interconnected nodes (neurons) that process inputs. The **denoising model** is typically a **probabilistic model**, which assigns a probability distribution to the input data. The **loss function**, a mathematical function that measures the difference between the model's predictions and the true data, is used to train the denoising model. Key terms include **diffusion steps**, the number of iterations in the diffusion process, and **noise schedule**, a schedule that controls the amount of noise added at each diffusion step. Understanding these concepts is crucial for a practitioner to work with diffusion models, which have applications in image and video generation, among other areas.

The core idea is to progressively add noise to the input data until it becomes indistinguishable from random noise, and then learn to reverse this process to generate new data samples. 
**Diffusion steps** refer to the number of times the noise-adding operation is applied, with each step consisting of a **forward diffusion process** that adds noise and a **reverse diffusion process** that learns to denoise the input. 
A **noise schedule** is a sequence of noise variances that control the amount of noise added at each diffusion step.

Understanding these core definitions and principles is essential for working with diffusion models in computer science applications such as image and video generation, data augmentation, and anomaly detection.

## Mechanisms

Diffusion models in computer science operate through a series of transformations that progressively refine the input data, typically images, to generate new samples that resemble the training data. The process begins with a Markov chain that iteratively refines the input noise signal until it converges to a data distribution. The key steps involve: 
1. **Noise Schedule**: Initializing the process with a random noise vector, which serves as the starting point for the diffusion process.
2. **Forward Diffusion Process**: A series of transformations that progressively add noise to the input data, creating a sequence of noise-perturbed versions. Each step in this process is based on a noise schedule that controls the amount of noise added at each step.
3. **Reverse Diffusion Process**: This is where the model learns to reverse the diffusion process, transforming the noise back into the original data distribution. It involves a series of neural network transformations that progressively denoise the input.
4. **Denoising Model**: A neural network trained to predict the noise that was added at each step of the forward diffusion process. By subtracting this predicted noise, the model effectively reverses the diffusion step, moving towards the original data.
5. **Loss Function**: The training objective for the denoising model, typically a variant of the mean squared error or cross-entropy loss, which encourages the model to produce samples that are indistinguishable from the real data.
6. **Sampling**: Once trained, the diffusion model can generate new samples by starting with a random noise vector and iteratively applying the reverse diffusion process, using the denoising model at each step to refine the sample until it converges to a realistic data point. 
This step-by-step process underlies the ability of diffusion models to generate high-quality, diverse samples that capture the complexities of the training data distribution.

## Methods And Frameworks

Diffusion models in computer science utilize various methods and frameworks to generate, edit, and manipulate data, particularly images. The Denoising Diffusion Model is a key framework, which progressively refines the input data by reversing a diffusion process. The DDPM (Denoising Diffusion Probabilistic Model) is a specific implementation that uses a Markov chain to model the diffusion process. The formula for the DDPM loss function is L = E[∑(α_t * ||x_t - x||^2)], where α_t is the noise schedule and x_t is the noisy input. 
The DDIM (Denoising Diffusion Implicit Model) is another method, which uses a non-Markovian process to improve sampling efficiency. 
When to use: DDPM for image generation tasks, DDIM for faster sampling. Failure mode: mode collapse, where the model produces limited variations of the same output.

## Common Errors

In diffusion models, a common mistake is incorrectly setting the noise schedule, leading to unstable training or poor sample quality. This occurs when the variance of the noise schedule is not properly balanced, causing the model to either oversmooth or undersmooth the input data. Another error is using an inadequate number of diffusion steps, resulting in insufficient removal of noise or failure to capture complex data distributions. Furthermore, practitioners often overlook the importance of learning the reverse process, which is crucial for generating high-quality samples. Incorrectly assuming that the reverse process is a simple reversal of the forward process can lead to mode collapse or unrealistic samples. Additionally, failing to properly normalize the input data or using an inappropriate loss function can also hinder the performance of diffusion models. These mistakes can be mitigated by carefully tuning hyperparameters, monitoring training dynamics, and using techniques such as noise scheduling and batch normalization to stabilize training.
