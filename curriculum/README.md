# Sales King Academy — Curriculum Corpus

The `content/lessons/` directory contains structured lesson datasets. Each lesson is intended to carry instructional content, practice, and quiz material across the SKA mastery progression.

The `curriculum/` directory contains curriculum maps and subject-level learning structures.

The public corpus is deliberately separated from private learner state. Scores, attempts, mastery records, certificates, accounts, CRM data, payments, authentication material, deployment configuration, and secrets do not belong in this repository.

## Mastery progression

1. Foundations
2. Core Concepts
3. Intermediate Application
4. Advanced Undergraduate
5. Honors / Advanced
6. Graduate Study
7. Doctoral Preparation
8. Research & Frontier

Content is expanded incrementally: subject by subject, lesson by lesson, with explanations, examples, practice, quizzes, assessments, remediation, and application work.
