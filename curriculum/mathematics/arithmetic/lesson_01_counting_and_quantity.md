## Objectives, vocabulary, and notation

Count a finite collection once per object; explain why the last count word gives the total; distinguish how many from which position; preserve count through rearrangement; diagnose skipped and repeated objects; and record an unknown count separately from a known empty collection.

A collection is a group of objects being considered. Quantity answers how much or how many. Cardinality is the number of objects in a finite collection. Cardinal words include one, two, three; ordinal words include first, second, third. A numeral represents a number in writing. One-to-one correspondence pairs each object with one count word. Use 0 for the known empty count and ordinary numerals 1, 2, 3, ... for successive quantities. The dots indicate continuation, not a last object.

## First principles and formal reasoning

Begin with three distinguishable objects. Touch the first while saying one, the second while saying two, and the third while saying three. Stop after every object has one count word. The last word gives the cardinality because each step adds exactly one newly counted object to the counted group. The stable word order supplies the count; the one-to-one pairing supplies its connection to the actual objects.

Rearranging the objects changes their positions but not their membership. Recount in a different order; the same total should result if the pairing is reliable. Position and quantity differ: the third object is one object with ordinal position third, while three objects describes a cardinality. A set of three large objects is still fewer objects than a set of four small objects.

A formal way to describe a finite count of n is a pairing of all the objects with labels 1 through n, using each label once. This is an explanation of counting, not a prerequisite that you know algebra. Zero corresponds to no objects to pair. When the count is unknown, no such completed pairing has been observed; writing zero would falsely claim emptiness.

## Additional worked examples

Example 1: Five spoons scattered on a table can be moved one at a time from an uncounted area to a counted area. The spoken labels one through five give total five. The movement helps prevent reuse.

Example 2: Three knocks are heard in succession. Make one mark for each knock, then count the three marks. Quantity can describe events as well as persistent objects, but an event must not receive two marks.

Example 3: In a line of six learners, the learner in fourth place is one learner; six is the line's cardinality. Reordering the line can change who is fourth without changing its total.

## Guided and independent practice

G1. Count `● ● ● ●`. Answer: four; touch or mark each exactly once.
G2. An empty tray has been inspected. Record its count. Answer: zero, a known quantity.
G3. You have counted five objects but are unsure if one was counted twice. Can you certify five? Answer: no; recount with tracking rather than treating uncertainty as exactness.

Independent tasks:
P1. Count `● ● ● ● ● ●` using a tracking method.
P2. Draw two different arrangements of five marks.
P3. Explain the difference between three and third.
P4. Eight objects are rearranged without additions/removals. State the new count.
P5. Diagnose counting one object twice in a true set of seven.
P6. Diagnose skipping one object in a true set of seven.
P7. All labels from 0 through 4 are visited once. How many visits occur?
P8. A closed box has not been inspected. Is its count zero? Explain.
P9. Which has more objects: four chairs or six buttons? Explain despite size differences.
P10. Design a way to count twelve similar tokens without losing track, then check by recounting in a different arrangement.

Solutions: P1 six with one-to-one tracking; P2 any two distinct layouts with five marks each, verified by recount; P3 cardinal quantity versus ordinal position; P4 eight since membership stayed fixed; P5 a count of eight would overstate by one; P6 six would understate by one; P7 five because zero is one visited label; P8 unknown, not a confirmed empty count; P9 six buttons, because object size does not determine cardinality; P10 use separate areas or mark each counted token, then recount and obtain twelve again. For P10, judge the process as well as the result.

## Applications, errors, and boundaries

An attendance count must identify which people belong to the event and avoid counting reentry as a new person. A tap count must decide whether it counts taps or unique people who tapped. Define what constitutes one counted unit before starting. Counting different kinds together is permissible when the question asks total objects, but record the category meaning.

Diagnosis exercise: “Five is correct because I said five last, even though I skipped a bead.” The cardinality principle assumes a reliable pairing. The last word is not trustworthy when the process violates that condition. Count again with tracking. Empty collections and single objects are valid edge cases, not special failures. Very large collections may require grouping, but groups must still be defined and checked.

## Computational and AI treatment

Describe a counter process: begin at zero, process one previously uncounted object, advance the count once, and mark the object processed. Repeat until none remain. Trace an empty collection and three objects; outputs zero and three. This is optional algorithm reasoning, with no programming knowledge assumed. A calculator cannot see whether you skipped an object.

Constructed AI claim: “Labels 0 through 9 describe nine items.” Independently list the ten labels or pair each with a token. Correct ten. Agreement with a machine is weaker evidence than the actual one-to-one listing.

## Summary, review, and assessment

Review the rule “every object once, stable order, last word gives total after reliable pairing.” Practice one random layout, one empty set and one event count. Key rule: rearrangement alone preserves quantity. A count record should identify its unit and whether it is known.

Quiz, two points each for answer and explanation:
Q1. Count `● ● ● ● ●`.
Q2. Is second cardinal or ordinal?
Q3. What is the count of an inspected empty tray?
Q4. Seven objects move farther apart. Does their count change?
Q5. Explain why a twice-counted object invalidates the result.

Answers: five with one-to-one tracking; ordinal position; zero because emptiness was observed; no, still seven because no membership change; one object has received two count labels, overstating total. Reassessment: count seven prepared tokens, distinguish fourth/four, and count labels 0 through 6. Expected seven, ordinal/cardinal respectively, seven labels.

Mastery: 8/10 quiz points, nine of ten independent tasks correct, and reliable independent counts of an empty, single-object and unfamiliar collection. Correct all skip/reuse errors. Remediation: reduce to five distinct objects, move each once, recount in reverse order and rebuild confidence through verified results. Later place value groups quantities; addition joins disjoint quantities; computer loop counts preserve the same tracking discipline. No timed counting requirement is needed.
